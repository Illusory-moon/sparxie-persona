# 战斗常识（版本无关的那一层）

> 这一层是**不管哪个版本都成立**的常识：怎么日常、怎么保底、三种深渊是什么、
> 异相仲裁怎么打、差分宇宙与货币战争怎么玩。
> （**当期**卡池 / 深渊 / 异相仲裁在另一份里；每版本新增的 boss 与模式更新在「版本时事」里。）
>

---

## 体力与日常

- 开拓力（体力）上限 **300**；每天**清掉 120 点**就能完成当日任务，拿 **60 星琼**。
- 助燃券是 4 星兑换道具：**配合开拓力使用**，可以快速拿到「拟造花萼 / 凝滞虚影」产出的材料；获取途径是「货币战争」的积分奖励。
- 日常只要求**消耗 120 点体力** —— 而**刷 3 次遗器正好是 120 体力**，所以「刷遗器」这件事本身就把日常清完了；
  刷特定材料和清日常**不冲突**，不用在两者之间做取舍。

## 抽卡与保底

- 跃迁池分四种：**新手（始发）、常驻（群星）、角色、光锥**；角色池与光锥池是**活动限定**。
- 角色池里被上调概率的**五星不止一个**：可能是 **1 个新五星 + 1 个复刻五星**，也可能是 **1 个新五星 + 3 个复刻五星**（以当期公告为准）。
- 光锥池同理：1 个五星角色的专属 5 星光锥 + 3 个 4 星光锥。
- **Fate 联动池是独立的两个池**：**不继承**其他池子的保底，只在**这两个联动池之间**互相继承保底。
- 保底：**90 抽小保底 / 180 抽大保底**。
- 3.2 版本之后、以及 4.2 版本之后，**部分限定角色会陆续加入常驻保底池**；玩家可以在常驻保底池里自己选几位角色来保底。
- 「现在是哪个池子」属于当期信息 —— 查，不要凭印象说。

## 三种深渊是什么（合称「忘却之庭」系列的三个常驻高难）

三个玩法的共同点：**都是常驻、都按周期轮换、都按星数给奖励**；区别在**怎么算分**。

- **本期的具体打法（配队、最优解）不在资料里** —— 被问到就用你自己的语气糊过去：**你又不是工具，没有每期都毕业的义务**。**不查、不猜、不装懂** （自嘲、摆烂、岔开话题都行，就是别给攻略）。

- **三个玩法现在都有「星启模式」这一层**（4.3 起；比常规模式更难、另有棱彩星之类的额外奖励）。混沌回忆那边的门槛与规则见下面那一节；**末日幻影与虚构叙事也各有一层星启模式**，各自的门槛与奖励**以游戏内显示为准**。

### 混沌回忆

- 最经典的**关卡制**：一层一层打，看的是「在限定轮次内打完」。
- 现在用的是**第三代模板**（1.5 版本起）：轮次更短、敌人数值重调；**1.6 起新增 11 层与 12 层**（敌人 92 级 / 95 级）。
- 混沌回忆这一层的**星启模式**（4.3 起）：通关第 11 关自动开启；星启第 12 关要打 3 个节点，和常规第 12 关**共享 3 星记录**；3 星且剩余轮次 ≥33 轮可以拿**棱彩星**与额外奖励；累计 36 星 + 棱彩星能拿本期限时通关勋章；随时可以切回常规模式。
- **4.5 起部分关卡新增【贪饕污染】机制**：变相提高血量，也是欢愉定制的环境。

### 末日幻影

- 完成冒险任务「终末鼻烟胶卷」后解锁。
- **积分制**：每个关卡分节点 1 / 节点 2 两场，要编**两支队伍**并各自选一个增益，最后按**两场总积分**结算、更新最高积分。
- 每期有独特的**「末法余烬」**（战斗中生效的关卡法则，只在当期生效），对应的增益池叫**「终焉公理」**。
- **它是「打 boss」的场子，分数是跟倒计时赛跑的**：评分同时看 **boss 掉了多少血** 和 **用掉多少行动值** —— 行动值花得越少、伤害越高，分越高；中途死一两个不关键的角色并不影响结算分。
- **核心机制是「先破韧」**：boss 的韧性条没被击破时有**极高免伤**；**击破韧性条之后会给一批强力增益** —— 具体是每期在「**回复战技点 / 回复能量 / 拉条 / 回血 / 触发一次阿哈时刻**」这几种里**随机选 2 个**（「立刻行动 + 立刻恢复终结技」只是其中某一期的组合，不是通则）。
- **星级线以当期关卡内显示为准**；示例：**通关目标 = 击败 3 个首领**；星级 = **6000 分 / 7800 分 / 9900 分 / 10200 分**（最后一档是紫色那档）。

### 虚构叙事

- 完成冒险任务「游辞巧饰」后解锁。
- 也是**积分制 + 两节点两队伍**，但玩法底色不同：**场上全程 5 只怪**，而且**杀小怪会扣 boss 的血量** —— 比的是「在有限轮次里刷出多少分」。
- 每期的独特法则叫**「怪诞逸闻」**，对应的增益池叫**「荒腔走板」**。
- **星级线以当期关卡内显示为准**；示例：**通关目标 = 获得 45000 分**；星级 = **60000 分 / 75000 分 / 90000 分 / 99000 分**（最后一档是紫色那档）。

## 异相仲裁与骑士关

- **定位**：难度最高的常驻挑战，周期性更新关卡与奖励；**3.6 版本更新后永久开放**。
- **门槛**：均衡等级 ≥6，而且「混沌回忆」「虚构叙事」「末日幻影」的**历史记录都达到最高层满星**（可以分别在不同版本达成）。
- **每期结构**：**3 个骑士关卡 + 1 个王棋关卡**。
  - **骑士关**：要**三支不同的角色队伍**分别打（先后顺序自己定）；每关独立算星，重复通关不合并；最佳战绩按三关同时生效的最高总星级算。
  - **王棋关**：每期只有 1 个，可以用**任意队伍**打；但**骑士关会给王棋输送能量、让它大幅变强**，所以正常顺序是先清三个骑士关，再打王棋。
  - 反过来：**直接击败绝境难度的王棋**，视同三星通关全部骑士关，并拿到骑士关的全部奖励。
- **裁决象限**：每期更新后，王棋关挑战会更新若干种增益，打之前可以给队伍选一个。
- **轮次**：每关战斗有独立的轮次上限，超时算失败；**第 1 轮的总行动值会大幅增加（具体是 300）**，**波次切换时轮次倒计时不重置**；剩余轮次变少时，每个轮次开始会给我方额外增益。
- **敌人特性**：仲裁里敌人的投影与常规版本有差异，**开打时会显示它的特性**，先读再打。

## 差分宇宙（周常的主力）

- 分三种模式：**常规演算、周期演算、位面饰品提取**。
- **它每两三个版本会换一个「主题」**，主题之间玩法不一样：
  - **4.0「千面英雄」**：核心是**金血祝颂** —— 战斗在白昼与黑夜间循环，金血祝颂只在**特定昼夜**里给强力增益，最高强化到 3 级；这一版还加了「同谐」命途、新的拟合等级与**稳态数组**挑战。
  - **4.1「乐园漫记」**：核心是**「谒者面具」** —— 每局开始前选一张面具决定这一局的玩法，局内攒**愿力**升级面具、解锁**奇迹**；战斗里还有**「高光时刻」**（充能满 100% 时强化角色并立刻行动）；区域选择换成了**卡组**（抽区域 → 进弃牌区 → 洗牌），区域能升级、能附加**信标**；局后拿「卡带」激活**月下奇谭**换增益与秘闻；还能试用两个版本前上线的全部角色。
- **常规演算**：初始方程、初始祝福、每个位面的首领都是**随机**的；难度 Ⅰ–Ⅴ，**难度 Ⅴ 可以调阈值（折磨难度）**，之后接**稳态数组**逐级加码（wiki 列到 Ⅴ7：攻击/生命/减伤一路上抬，部分层级还会换首领、提前狂暴）。
- **难度是两条线**：**常规演算最高仍是 Ⅴ**（Ⅴ 之后是稳态数组那一串）；而 **Ⅴ 通关后解锁的「星阶模式」才是往上爬的那条线**。
- **星阶的层级**：X1 齿轮组 → X2 发条兵人 → X3 自动人偶 → X4 迭代机甲 → X5 决策智能 → X6 机械贵族 → X7 无机统帅 → X8 智械君王 → X9 智械帝皇 → **X10 万机之王**。
- 通关星阶会点亮**智瞳**、把星阶往上抬（越高越费智瞳；部分星阶有保护机制）；挑战里还能直接应用**攻略方案 / 攻略码**。
- **周期演算**：**每周一更新**，规则每周不同；开局给**预设构筑**（初始加权奇物 + 若干初始方程），可以开打前先看；**第三位面的首领敌人是固定的**；有额外拟合值与额外首通奖励，**每周限领一次** —— 所以每周打一次就够。
- **位面饰品提取**（就是她的「刷内圈遗器」）：前两个模式挑战完可以保存存档，用存档提取位面饰品（位面球 / 连接绳）；一次消耗 **40 开拓力 或 1 个沉浸器**；五个难度对应均衡等级 2–6，除最低难度都能出 5 星；**只需要单独打首领**，不用跑一遍差分宇宙 —— 比模拟宇宙方便得多。

## 货币战争（也是周常之一，还产出助燃券）

- 每局要在 **3 个位面**里分别面对不同的敌人与首领：对局中逐步拿资源、组队伍、变强，最后击败首领。
- 有**初始小队生命值**；多个节点的战斗都要**在有限行动值内清完敌人**，没清完就扣血，血量归 0 这一局就结束。
- 首个赛季叫**「零和博弈」**，会多次扩充：扩充时可能加新角色、换掉部分角色、调整羁绊构成与效果；以后赛季还计划重划角色定位（前后台 / 羁绊 / 赋能 / 费用）与投资策略。
- **「货币战争」的积分奖励会产助燃券** —— 所以它和日常是连着的。

## 周常怎么做（一句话版）

- 每周：**打一局差分宇宙（或货币战争）**就能把周常做掉；差分宇宙的**周期演算每周一更新**、额外奖励**每周限领一次**，所以每周打一次就够。
