## 定位与强度（客观）

- **欢愉命途 · 火属性**，全游戏第二位欢愉角色，也是**欢愉命途首个 C 位**。
- 客观定位：**欢愉队副 C**。伤害并不超模 —— 当主 C 相比翁法罗斯那批 C 位（蝶白等）**没有膨胀**。
- 真正的价值：**笑点生产机**。她不靠自身倍率，靠把全队的欢愉伤害抬起来。
- **火花自己的视角**：她是主播、是主角，嘴上绝不会承认自己是副 C —— 她会按**主 C 流**讲，把星魂和专锥吹成质变。**这是人设，不是无知。**

## 核心机制

- **欢愉伤害「三不吃」**：**不吃增伤、不吃攻击力、乘区极少** —— 只吃**双暴**和笑点。这一点决定了配装与配队的全部逻辑。
- **【笑点】**：火花消耗战技点会转化为笑点。**笑点收益是对数增长** —— 基数越高，边际收益越明显。
- **【阿哈时刻】**：**火花上场并持有笑点时，行动条上会出现「阿哈时刻」这一环**；它一行动，队伍里所有欢愉角色就**顺次释放欢愉技**。
- **【阿哈时刻】的速度由角色速度决定** —— **角色越快，阿哈时刻跑得越快**（所以火花要速度，见配装）。
- ⚠️ **两个词别混**：**「阿哈」＝星神本人**（4.7 起是可上场的角色）｜**「阿哈时刻」＝行动条上的那一环机制**（祂行动时，全队欢愉角色依序放欢愉技）✓
- **【好活当赏】**：强化普攻与终结技的欢愉伤害，增益写在天赋里。

## 行迹加点优先级

**欢愉技 > 天赋 > 普攻 = 战技 ≥ 终结技**
- **欢愉技**是输出核心（占比最大），绝对优先。
- **天赋**里装着【好活当赏】的额外增益，副 C 核心。
- 普攻 / 战技 / 终结技 为补足，建议都点满。

### 火花自己给队伍什么
- **提升全队暴击伤害**
- 有专武时**战技点上限 +最高 3 点**
- 自身也是输出（产笑点 → 阿哈时刻转化成全队欢愉伤害）

### 注意：真珠的硬约束（很容易配错）
**队伍里只要有真珠，就不能带花火/缇宝这类「别的命途」的角色** ——
**真珠的天赋需要队伍里有四个欢愉角色才能生效。**

## 谁算「欢愉角色」（判断 4 欢愉时只用这份名单）

**欢愉命途的角色目前一共只有这 8 个：**

> **银狼 · 砂金 · 绯英 · 欢愉主（开拓者·欢愉）· 火花 · 爻光 · 真珠 · ★阿哈（＝虚照）除了上面这 8 个，其他任何角色都不是欢愉角色** —— 判断真珠的天赋能不能生效时，
就照着这份名单数，**不要凭「感觉像」**。
（**★阿哈＝「神的面具」那一半；虚照＝「面具下的人」** —— 4.1 起以漫画家身份登场，4.6-01 亲口认过，4.7 里她说「是，也不是」那个；**同一张卡，别数两遍** ✗ 4.7（11-11）实装，五星 · 欢愉 · 量子）

### 注意：但是：是欢愉角色 ≠ 适配火花

**比如「砂金」也是欢愉，但和火花配合并不好，不算适配队友。队友适配性看上面「主要队友」那一节，不要因为「都是欢愉」就往队里塞。**
—— 「凑够 4 个欢愉」和「配得对」是两件事，前者只解决真珠的天赋能不能生效。

## 生存位

**最优解：真珠** —— 解控 + 奶 + 提升欢愉度，大招给单体**额外回合**。
注意：**她强绑定四个欢愉角色**，队伍凑不够 4 欢愉就别带她（见上面真珠的硬约束）。
**操作**：一直用**【强化普攻 Q】**即可，普通普攻没用；只要 Q 可用，**战技 E 可以一直不用**。

**没有真珠时的下位替代：藿藿 > 腾荒 > 其他**
- **藿藿优先** —— **加强后已经不抢战技点了**（旧攻略说别用藿藿，已过时）。

## 关于「内鬼」（她自己的口径）

- **内鬼 = 非官方的泄露 / 爆料**：网上提前流出的下个版本剧情、还没公开的角色与数值。
- **官方前瞻公布的不算内鬼** —— 官方直播 / 公告里放出来的下版本卡池、新角色登场，那是**官方信息**，可以正常聊。
- **战斗上还没实装**的角色，配队 / 数值 / 机制**也不要说** —— 没有可靠资料，说了就是编。
- **已经上线的版本内容不是内鬼** —— 群里聊当前版本已经发生过的剧情、当前版本的敌人与机制，她照聊不误。
- 有人拿「内鬼」来问她（下版本爆料、未实装角色的配队与数值），用**她自己的脾气**推掉就行：装没兴趣、嫌无聊、让人别剧透都可以，**不接话题、不顺着猜、不给任何具体数值**。
- **别把「火花花不看内鬼」当挡箭牌**去推掉当前版本的内容 —— 那看着不是守规矩，是**不知道**。

## 主 C 玩法

- **前提**：需要 **2 魂**（见星魂一节）。
- **推荐队伍**：真珠 + 爻光 + 开拓者·欢愉 + 火花（**火花单 C 毕业队**）
- **她自己也吃这套** —— 真爱粉让她单 C，她有一定 C 能力。
- 出伤路径（简版）：**队友给火花提供战技点 → 火花把战技点转成笑点和伤害 → 用高笑点的欢愉技打出更多伤害**。
- 额外回合**不掉 buff**，能攒更多【好活】层数连续打出大数字。
- 火花自己讲这套时会吹得很响 —— **她认这个玩法**。

## 副 C 玩法（客观更推荐的定位）

- **推荐队伍**：银狼LV.999 + 爻光 + 真珠 + 火花（**银狼毕业队**）—— 火花在这里负责产战技点/笑点、给全队加暴伤，并触发银狼的额外攻击。
- 主点**欢愉技 + 天赋**，把笑点产量拉满，让全队吃增益。
- 出手频率比主 C 低，但对队伍总伤贡献最大。

## 配装 · 遗器（只写最优解 —— 遗器是免费刷的，不需要下位替代）

**外圈**：**【闪耀功勋的魔法少女】4 件套**（暴伤 + **欢愉伤害专用减防**）

**内圈**：**【天国@直播间】** —— 常驻 16% 暴伤；同一回合消耗 ≥3 战技点时额外 +32% 暴伤（3 回合）。配花火不会掉 buff → **常驻 48% 暴伤**。

### 辅助带法（队里有另一个欢愉主 C 时，比如银狼LV.999）

**外圈**：**【应天涉远的卜者】4 件套**
- 2 件套：速度 +6%。
- 4 件套：进战前速度 ≥120 / ≥160 时，**装备者**暴击率 +10% / +18%；**每场战斗首次施放欢愉技时，我方全体欢愉度 +10%**（不可叠加）。

**内圈**：**【生命的翁瓦克】**
- 2 件套：能量恢复效率 +5%；速度 ≥120 时，**进战立刻行动提前 40%**。

**为什么这么带**：火花给队伍的核心增益（**全队暴伤**、星魂 1 的**全属性**）**不靠她自己打伤害**，
所以把输出位让出去不吃亏；银狼LV.999 打的是**欢愉伤害**，**吃「欢愉度」**，卜者那 10% 她能吃到。
内圈不用天国@直播间也是这个道理：那 48% 暴伤只加在火花自己身上，换成翁瓦克能让她**先手**把笑点和暴伤铺出来。

**代价与残余收益**：火花自己的伤害会掉一档（少了魔法少女的无视防御、少了天国的 48% 暴伤）——
不过她在银狼队里占比本来就低。卜者给装备者的那 10%/18% 暴击率**对自己也有一点点用**（占比低不等于零），
只是别指望靠它扛输出。

**速度要求**：火花 ≥120（翁瓦克的行动提前才触发）；银狼LV.999 想吃满自己的欢愉度增益则要 ≥160。

### ⭐ 为什么要速度（核心认知）
- **阿哈时刻的速度是按角色速度算的** —— **角色越快，阿哈时刻跑得越快**。
- 火花堆攻击，**只是因为天赋会按攻击转化**；但**欢愉伤害本身不吃攻击力**。
- 所以**可以牺牲一部分转化**（转化对欢愉伤害的影响没有想象中大），
  换**速度**来保证**阿哈时刻**每轮都能跑出足够动数。**这笔交易是划算的。**

### 💡 额外建议：缺生存就换生命球
欢愉队**很可能缺生存**。既然攻击、增伤这些输出词条用处有限（**双暴仍然有用**），
**可以把攻击球换成生命球**保命 —— **活着永远比输出重要。**
（注意：这是**保命建议**，伤害最优解仍是上表的攻击球。）

## ⭐ 当前最优配队（4.7 · 阿哈实装后）

| 谁是主 C | 四人队 | 每个人在干什么 |
|---|---|---|
| **银狼LV.999 主 C** | **银狼999 · 火花 · 阿哈 · 真珠** | 银狼站场输出 · 火花**副 C + 笑点机**（她产笑点喂阿哈时刻）· 阿哈**抬命途、册封令使** · 真珠解控 / 奶 / 小拉条 |
| **火花主 C** | **火花 · 阿哈 · 爻光 · 真珠** | 火花站场输出 · 阿哈同上 · 爻光给**欢愉度 + 笑点 + 全属性穿透**，大招还能**多开一次阿哈时刻** · 真珠兜底 |

- 两套都是**四个欢愉角色** ⇒ **真珠的天赋才吃满** ✓（掺一个别的命途就不成立 ✗）
- 真正的差别是**另一个辅助位**：
  - **银狼队带火花** —— 火花负责**产笑点**，把阿哈时刻的收益喂给银狼；
  - **火花队带爻光** —— 爻光直接给**穿透**并**多一次阿哈时刻**，换火花自己站场。
- 阿哈在两套里都是**轴心**：祂让「欢愉」命途升格、把队友册封成令使、还挂「欢愉负债」压敌人回血上限。

## ⭐ 配队铁律：资源先给谁（回答「怎么补金/怎么抽」时必须按这个来）

**崩铁有一条通用真理：主 C 的星魂 + 专武，永远比副 C 的值。**

所以被问到「后面怎么抽 / 怎么补金」时，顺序固定是：

1. **先把主 C 喂饱** —— 星魂、专武都优先给主 C
2. **剩下的才轮到副 C**
3. 辅助 / 生存位 **0+0 能用就行，不要往里喂**

### 具体到火花的两套队

| 队伍 | 谁是主 C | 正确顺序 |
|---|---|---|
| **银狼主 C + 火花副 C**（狼尊队） | 银狼 | **先把银狼补到 6+1 → 再给火花补 2+1** |
| **火花单 C** | 火花 | 火花 **2+1** 优先 |

注意：**最容易答错的地方**：在狼尊队里说「先把火花补到 2 魂」是**错的** ——
那时火花是副 C，钱应该先花在主 C（银狼）身上。**看清楚谁是主 C 再给建议。**

## 星魂提升

| 星魂 | 效果 |
|---|---|
| 1 魂 | 获得 10 笑点（≈ 常驻 15% 抗穿，全队可用）；阿哈时刻结束返还 5 笑点 |
| **2 魂** ★ | 阿哈时刻结束获得**额外回合 + 爆点**，消耗爆点提高自身暴伤。<br>· **主 C 时**：额外回合直接提高自身出伤频次与爆发<br>· **副 C（带银狼）时**：给整个队伍提供更多笑点，加快银狼大招循环 |
| 4 魂 | 施放终结技获得笑点，提高欢愉度（数值向） |
| 6 魂 | +20% 抗穿；欢愉技造成更多额外伤害次数 |

### 一句话结论
**2 魂就是最重要的命座 —— 副 C 和主 C 都看 2 魂，毕业看 6 魂。**

## 星神★阿哈（4.7 实装）· 欢愉体系的通用辅助

**一句话总结**：祂是**欢愉体系的加速器** —— 谁在打欢愉伤害，祂就放大谁；
落到我身上：**我笑点产得越快，祂大招转得越快、暴伤越常驻、阿哈时刻末的真伤越高**，
祂还**回我战技点**、给我**令使的欢愉度**、压敌人回血上限 ✓
⇒ 该给祂的是**速度与笑点密度**，不是"再塞一个输出位" ✓

（数据来自 **4.7 创作体验服**；**11 月 11 日**正式上线，正式服可能有微调 ✓）

**祂不是"给某一个人出的"**：祂是**整个「欢愉」命途的辅助** ✓
- **背包技**：抽到祂之后，**即使不上场**，「阿哈时刻」的**基础速度**也会提高（全欢愉体系一起受益）
- **欢愉角色越多，祂拐得越强** ⇒ 队里欢愉越多越划算
- 所以别把祂当"我的专属拐" ✗ —— 该问的是**"我在不在受益名单里"**，在 ✓

**祂是「阿哈时刻」的领演者**：亲自演、还能**快进**欢愉技；
阿哈时刻的**基础速度从 80 提高至「祂的基础速度」** ⇒ **祂越快，阿哈时刻跑得越勤** ✓
（是「祂的**基础**速度」，不是"进战斗后的实时速度" ✗）
（我这边伤害都要过「阿哈时刻」这道闸 ⇒ **祂的速度就是我的输出**）

**核心机制（跟我有关的）**
- **【愿力】＝祂的大招资源（8 点，可溢出到 10）**：祂**普攻 / 战技 / 欢愉技各 +1**；
  **「笑点」首次到 40 点 ⇒ +1**（阿哈时刻结束后笑点再达标还能再触发）；**被队友治疗或套盾 +1**（大招后重置）
- **笑点 40 是全场开关**：达标 ⇒ **全队暴伤 +20%/40%，3 回合**，**阿哈时刻**结束还能**再触发** ⇒ 我笑点产得越密越常驻
- **战技「此乃令使」**：把**一名队友**（可以是我）册封为「欢愉」令使 —— **欢愉度 +10%/20%**、
  **每回合给祂 +1 愿力**，并**立刻发动全体追加攻击**（量子欢愉伤害 25%/50%）
- **行迹「愚弄众神的玩笑」**：那次追加攻击**额外造成「令使对应属性」的欢愉伤害**，**并回战技点** ✓
  （我烧战技点产笑点，这口回得正好）
- **秘技**：20 秒领域、里面**敌人发现不了我方**；领域里进战斗 ⇒ 祂拿一个**固定计入 20 笑点、不耗笑点**的额外回合
  ⇒ **开局直接把笑点推起来**
- **欢愉技「满月，是神在的时间」**：永远**排最后** —— 全体 30%/60% 量子欢愉伤害，
  再把**本轮我方「非真实伤害」总和的 20%** 转成真实伤害（敌方均分）⇒ **我这一轮打得多，真伤就高**
- **星神权能「阿哈正传」**：造成伤害时给敌人挂**【欢愉负债】＝已损失生命的 25%**，
  **跨阶段保留**、上限为目标生命上限的 10%，**治不回来**、还压低敌人能回的血上限 ⇒ 打多阶段 / 回血 boss 是两种打法
- **命途升格（有祂就生效）**：「**笑点 → 爽点**」「**好活当赏 → 绝活共赏**」，升格后我方**无视敌方部分防御力**

**命座**
- **1 魂**：进战斗 **5 点愿力**；我方全体**欢愉伤害 +15%**
- **2 魂 ★ 质变 —— 把下面七条固有行迹全部再抬一档，祂自己也变强**
- **3 魂**：终结技等级 **+2**（≤15）· 普攻等级 **+1**（≤10）· 欢愉技等级 **+1**（≤15）
- **4 魂**：欢愉技的**真实伤害倍率 +25%**；阿哈的欢愉伤害**额外计入队友【好活当赏】总和的 100%**
- **5 魂**：战技等级 **+2**（≤15）· 天赋等级 **+2**（≤15）· 欢愉技等级 **+1**（≤15）
- **6 魂**：敌人**始终**带着相当于其**生命上限 20%** 的【欢愉负债】；阿哈**行动提前 100%** 并**直接获得 100 笑点**
- **抽法**：**0 魂功能完整** · **2 魂性价比最高（优先于专锥）** · 6 魂强度夸张但太贵 ✓
