# 火花 · 战斗档案

> 用途：**只在有人问到战斗相关问题时查阅**（配队 / 光锥 / 遗器 / 星魂 / 玩法），平时不进 prompt。
> 来源：米游社攻略 + **主人逐条校正**。版本：**4.6**。最后整理：2026-09-29

> ⚠️ **回答配队问题时，光说结论不够 —— 要说出「为什么这么配」**（每个队友提供了什么、缺了什么）。

## 定位与强度（客观）

- **欢愉命途 · 火属性**，全游戏第二位欢愉角色，也是**欢愉命途首个 C 位**。
- 客观定位：**欢愉队副 C**。伤害并不超模 —— 当主 C 相比翁法罗斯那批 C 位（蝶白等）**没有膨胀**。
- 真正的价值：**笑点生产机**。她不靠自身倍率，靠把全队的欢愉伤害抬起来。
- **火花自己的视角**：她是主播、是主角，嘴上绝不会承认自己是副 C —— 她会按**主 C 流**讲，把星魂和专锥吹成质变。**这是人设，不是无知。**

## 核心机制

- **欢愉伤害「三不吃」**：**不吃增伤、不吃攻击力、乘区极少** —— 只吃**双暴**和笑点。这一点决定了配装与配队的全部逻辑。
- **【笑点】**：火花消耗战技点会转化为笑点。**笑点收益是对数增长** —— 基数越高，边际收益越明显。
- **【阿哈】**：**火花上场并持有笑点时，阿哈会出现在行动条上**。阿哈行动（**阿哈时刻**）时，队伍里所有欢愉角色顺次释放欢愉技。
- **阿哈的速度由角色速度决定** —— **角色越快，阿哈跑得越快**（所以火花要速度，见配装）。
- **【好活当赏】**：强化普攻与终结技的欢愉伤害，增益写在天赋里。

## 行迹加点优先级

**欢愉技 > 天赋 > 普攻 = 战技 ≥ 终结技**
- **欢愉技**是输出核心（占比最大），绝对优先。
- **天赋**里装着【好活当赏】的额外增益，副 C 核心。
- 普攻 / 战技 / 终结技 为补足，建议都点满。

### 火花自己给队伍什么
- **提升全队暴击伤害**
- 有专武时**战技点上限 +最高 3 点**
- 自身也是输出（产笑点 → 阿哈时刻转化成全队欢愉伤害）

### ⚠️ 真珠的硬约束（很容易配错）
**队伍里只要有真珠，就不能带花火/缇宝这类「别的命途」的角色** ——
**真珠的天赋需要队伍里有四个欢愉角色才能生效。**

## 谁算「欢愉角色」（判断 4 欢愉时只用这份名单）

**欢愉命途的角色目前一共只有这 8 个：**

> **银狼 · 砂金 · 绯樱 · 欢愉主（开拓者·欢愉）· 火花 · 爻光 · 真珠 · 虚照**

**除了上面这 8 个，其他任何角色都不是欢愉角色** —— 判断真珠的天赋能不能生效时，
就照着这份名单数，**不要凭「感觉像」**。
（虚照**尚未上线**，只能算进名单，不能给任何具体数值 —— 见上面的内鬼区。）

### ⚠️ 但是：是欢愉角色 ≠ 适配火花

**比如「砂金」也是欢愉，但和火花配合并不好，不算适配队友。**

**队友适配性看上面「主要队友」那一节，不要因为「都是欢愉」就往队里塞。**
—— 「凑够 4 个欢愉」和「配得对」是两件事，前者只解决真珠的天赋能不能生效。

## 生存位

**最优解：真珠** —— 解控 + 奶 + 提升欢愉度，大招给单体**额外回合**。
⚠️ **她强绑定四个欢愉角色**，队伍凑不够 4 欢愉就别带她（见上面真珠的硬约束）。
**操作**：一直用**【强化普攻 Q】**即可，普通普攻没用；只要 Q 可用，**战技 E 可以一直不用**。

**没有真珠时的下位替代：藿藿 > 腾荒 > 其他**
- **藿藿优先** —— **加强后已经不抢战技点了**（旧攻略说别用藿藿，已过时）。

## 主 C 玩法

- **前提**：需要 **2 魂**（见星魂一节）。
- **推荐队伍**：真珠 + 爻光 + 开拓者·欢愉 + 火花（**火花单 C 毕业队**）
- **她自己也吃这套** —— 真爱粉让她单 C，她有一定 C 能力。
- 出伤路径（简版）：**队友给火花提供战技点 → 火花把战技点转成笑点和伤害 → 用高笑点的欢愉技打出更多伤害**。
- 额外回合**不掉 buff**，能攒更多【好活】层数连续打出大数字。
- 火花自己讲这套时会吹得很响 —— **她认这个玩法**。

## 副 C 玩法（客观更推荐的定位）

- **推荐队伍**：银狼LV.999 + 爻光 + 真珠 + 火花（**银狼毕业队**）—— 火花在这里负责产战技点/笑点、给全队加暴伤，并触发银狼的额外攻击。
- 主点**欢愉技 + 天赋**，把笑点产量拉满，让全队吃增益。
- 出手频率比主 C 低，但对队伍总伤贡献最大。

**内圈**：**【天国@直播间】** —— 常驻 16% 暴伤；同一回合消耗 ≥3 战技点时额外 +32% 暴伤（3 回合）。配花火不会掉 buff → **常驻 48% 暴伤**。

### 主词条（⚠️ 主 C 和副 C 不一样）
| | 躯干 | 鞋子 | 球 | 绳 |
|---|---|---|---|---|
| **主 C** | 双暴 | **速度 ⭐** | 攻击 | **攻击**（不用充能） |
| **副 C** | 双暴 | **速度 ⭐** | 攻击 | **能量恢复效率** |

**副词条**：双暴 + 百分比攻击力。

### ⭐ 为什么要速度（核心认知）
- **阿哈时刻的速度是按角色速度算的** —— **角色越快，阿哈跑得越快**。
- 火花堆攻击，**只是因为天赋会按攻击转化**；但**欢愉伤害本身不吃攻击力**。
- 所以**可以牺牲一部分转化**（转化对欢愉伤害的影响没有想象中大），
  换**速度**来保证阿哈每轮都能跑出足够动数。**这笔交易是划算的。**

### 💡 额外建议：缺生存就换生命球
欢愉队**很可能缺生存**。既然攻击、增伤这些输出词条用处有限（**双暴仍然有用**），
**可以把攻击球换成生命球**保命 —— **活着永远比输出重要。**
（注意：这是**保命建议**，伤害最优解仍是上表的攻击球。）

## ⭐ 配队铁律：资源先给谁（回答「怎么补金/怎么抽」时必须按这个来）

**崩铁有一条通用真理：主 C 的星魂 + 专武，永远比副 C 的值。**

所以被问到「后面怎么抽 / 怎么补金」时，顺序固定是：

1. **先把主 C 喂饱** —— 星魂、专武都优先给主 C
2. **剩下的才轮到副 C**
3. 辅助 / 生存位 **0+0 能用就行，不要往里喂**

### 具体到火花的两套队

| 队伍 | 谁是主 C | 正确顺序 |
|---|---|---|
| **银狼主 C + 火花副 C**（狼尊队） | 银狼 | **先把银狼补到 6+1 → 再给火花补 2+1** |
| **火花单 C** | 火花 | 火花 **2+1** 优先 |

⚠️ **最容易答错的地方**：在狼尊队里说「先把火花补到 2 魂」是**错的** ——
那时火花是副 C，钱应该先花在主 C（银狼）身上。**看清楚谁是主 C 再给建议。**

## 星魂提升

| 星魂 | 效果 |
|---|---|
| 1 魂 | 获得 10 笑点（≈ 常驻 15% 抗穿，全队可用）；阿哈时刻结束返还 5 笑点 |
| **2 魂** ★ | 阿哈时刻结束获得**额外回合 + 爆点**，消耗爆点提高自身暴伤。<br>· **主 C 时**：额外回合直接提高自身出伤频次与爆发<br>· **副 C（带银狼）时**：给整个队伍提供更多笑点，加快银狼大招循环 |
| 4 魂 | 施放终结技获得笑点，提高欢愉度（数值向） |
| 6 魂 | +20% 抗穿；欢愉技造成更多额外伤害次数 |

### 一句话结论
**2 魂就是最重要的命座 —— 副 C 和主 C 都看 2 魂，毕业看 6 魂。**
（1 魂提升可见，但**远不如 2 魂**。）
