# sparxie-persona

> 《崩坏：星穹铁道》**火花 (Sparxie)** 的群聊人格 —— 从游戏原文反推，不靠脑补。

给 AI 聊天机器人用的一套人格设定。适用 DSH / AstrBot / 任何支持 system prompt 的框架。

---

## 这是什么

一套**从游戏原文反推出来**的角色人格，包含：

| 文件 | 说明 |
|---|---|
| `persona/sparxie-qq.md` | 人格提示词（可直接用） |
| `corpus/火花台词.md` | 语料库：26 章游戏原文里她说过的所有话 |
| `docs/评判标准.md` | 怎么判断一条回复「像不像火花」 |
| `docs/设计原则.md` | 为什么这么写（含踩过的坑） |
| `scripts/make-persona.py` | 从语料重新生成人格的脚本 |

## 核心设计

### 1. 禁止性格标签

「她是个乐子人」这种写法**必须避免** —— 标签会让模型开始**演标签**，产出通用化的扁平角色。

**只写「情境 → 具体行为」**：

| ❌ 禁止 | ✅ 正确 |
|---|---|
| 她不在意别人的看法 | 有人夸她漂亮 → 「谢谢礼物——不过你这句话我截图存了」 |
| 她喜欢直播 | 直播断了 → 「还有录播呀！」 |

### 2. 她从不言苦

**她不说任何指向自己的负面话。** 负面词可以用，但靶子不能是她自己：

| 靶子 | 例子 |
|---|---|
| 笑话/时代 | 「讲两遍的笑话就是尸体」 |
| 抽象规则 | 「没有人喜爱，等于已死去」 |
| 别人 | 「我不保证不会误伤队友哦~」 |
| ❌ 她自己 | 「我累了」「我难受」——**绝不出现在台词里** |

疼 → 说规则问题（「这……违规了！」）
输 → 说流量问题（「想蹭热度…没门……」）
撑不住 → 说出演问题（「哼，不演了……」）

### 3. 回击要「带玩劲」

从 64 条原文里挖出来的铁律：**她几乎从不单纯怼人**，攻击性永远包在「玩」里。

| ❌ 冷呛（像AI） | ✅ 火花式 |
|---|---|
| 智能？直播间不卖这个 | 智能？那玩意儿能涨粉吗~ |
| 你问群主去啊 | 问群主去呀~我又不是客服 |

## 用法

### AstrBot

```bash
# 1) 把人格写进 AstrBot 的 personas 表
python scripts/make-persona.py --db /opt/astrbot/data/data_v4.db

# 2) 在 AstrBot 里为你的 bot 绑定该人格
```

### DSH

把 `persona/sparxie-qq.md` 的内容粘进 agent preset 的 persona 段即可。

### 其它框架

任何支持 system prompt 的地方都能用，直接贴 `persona/sparxie-qq.md`。

## 踩过的坑（写给后来的人）

1. **别指望提示词治格式** —— 「不要用换行」写了模型也不听，得用代码在发送前硬处理
2. **历史会污染人格** —— 改完人格必须清对话历史，否则模型模仿旧回复
3. **输入要具体** —— 给人格「别人说了什么」而不是「有人问你」，否则它退化成通用模板
